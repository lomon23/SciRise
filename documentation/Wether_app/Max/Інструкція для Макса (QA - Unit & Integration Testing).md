## 1. Об'єкт тестування №1: Django API (Python)

Ти маєш перевірити, чи Міша не зламав логіку відповідей.

- **Інструмент**: `pytest` + `pytest-django`.
    
- **Що тестуємо (Test Cases)**:
    
    - **Success Case**: Відправляєш "Lviv", перевіряєш, чи статус `200` і чи в JSON є поле `temp`.
    - **Empty Case**: Відправляєш порожній запит, очікуєш статус `400`.
    - **Not Found Case**: Відправляєш "Asgard", очікуєш статус `404`.
    - **Data Integrity**: Перевіряєш, щоб `humidity` завжди було числом від 0 до 100.
