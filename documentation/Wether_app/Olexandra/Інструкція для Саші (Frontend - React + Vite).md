Твоя задача — створити сучасний веб-інтерфейс, який буде «спілкуватися» з Django API та відображати дані згідно з дизайн-кодом у `base`.

## 1. Ініціалізація та стек

Використовуй **Vite** для швидкої збірки:
```
npm create vite@latest weather-front -- --template react
cd weather-front
npm install axios
```
- 
- **Axios**: для запитів до Django (краще за стандартний fetch через зручну обробку інтерсепторів).
- **CSS Modules** або **Tailwind**: на твій розсуд, але кольори та радіуси мають бути суворо з `base`.
## 2. Дизайн-система (CSS/Variables)

Обов'язково додай у `index.css` змінні, щоб дотримуватися стилістики:
```
:root {
  --bg-main: #1f1f1f;
  --bg-accent: #306c8c;
  --text-primary: #ffffff;
  --border-radius: 12px;
}
```
Використовуй `border-radius: var(--border-radius)` для карток погоди.
## 3. Архітектура компонентів

Розбий інтерфейс на модулі:

- **`SearchBar`**: поле вводу назви міста.
- **`CurrentWeather`**: головна плитка з `temp`, `humidity`, `advice`.
- **`HourlyForecast`**: горизонтальний список або графік (на 24 години).
- **`DailyForecast`**: список карток на 7 днів (тиждень).

## 4. Робота з API (Services)

Не пиши `axios.get` прямо в компонентах. Створи файл `src/services/api.js`:

```
import axios from 'axios';

const API_URL = 'http://localhost:8000';

export const getWeather = (city) => {
    return axios.get(`${API_URL}/weather`, { params: { city } });
};
```

## 5. Обробка стану (State Management)

- Використовуй `useState` для збереження даних погоди та `useEffect` для первинного завантаження.
- **Обов'язково**: додай стан завантаження (`loading`) та обробку помилок (якщо Міша поверне 404, виведи «Місто не знайдено»).
